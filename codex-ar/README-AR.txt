Codex العربي (نسخة غير رسمية)
==============================

هذه نسخة معرّبة غير رسمية من Codex CLI المفتوح المصدر (رخصة Apache-2.0).
ليست منتجاً من OpenAI ولا تابعة لها. الواجهة معرّبة، والنموذج يرد بالعربية دائماً.

طريقة التشغيل
--------------
1. فك ضغط المجلد codex-ar في مكان ثابت، مثل: C:\codex-ar
2. انقر مرتين على install.cmd (مرة واحدة فقط). هذا يضيف الأمر codex-ar إلى حسابك.
3. افتح مجلد مشروعك، ثم انقر بالزر الأيمن واختر "Open in Terminal".
4. اكتب: codex-ar ثم اضغط Enter.

ملاحظات
--------
- استخدم Windows Terminal حتى تظهر الحروف العربية متصلة وباتجاهها الصحيح.
- قد يُظهر ويندوز تحذير SmartScreen لأن الملف غير موقّع رقمياً. اختر "More info" ثم "Run anyway".
- تسجيل الدخول يتم بحساب ChatGPT أو مفتاح API كما في Codex الأصلي.
- هذه النسخة لا تحدّث نفسها تلقائياً. نزّل الإصدار الأحدث من صفحة Releases في المستودع.
- الكود والأوامر وأسماء الملفات تبقى بالإنجليزية عمداً.
